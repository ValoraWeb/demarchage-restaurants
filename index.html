Aperçu avant import

Activer le partage entre associés

Tant que rien n'est configuré, chaque personne a ses propres données dans son navigateur. Pour que vous et votre associé voyiez la même liste en temps réel (et donc que les doublons soient détectés entre vous), il faut brancher une base de données gratuite (Firebase). Le détail complet, étape par étape, est dans le fichier README.md livré avec l'outil. En résumé :

  1. Créer un projet gratuit sur console.firebase.google.com
  2. Activer « Firestore Database » (mode test)
  3. Copier le bloc de configuration fourni par Firebase
  4. Le coller dans index.html, à l'endroit indiqué « CONFIGURATION FIREBASE »
  5. Republier le fichier sur GitHub → le partage est actif
